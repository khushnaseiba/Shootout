# SHOOTOUT

### In this game there are so many drones and you have to destroy each game and you get close to a drone it will try to destro you

## CONTROLS

### A -> Left movement
### D -> Right movement
### Space -> Jump

## Getting Started

1. Install [Godot 4.7](https://godotengine.org/download/)
2. Clone the repo and open it in Godot
3. Hit Play (F5)

Or play it [in your browser](https://khushnaseiba.github.io/Shootout/)
